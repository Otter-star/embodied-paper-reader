# embodied-paper-reader

一个面向具身智能研究的论文阅读工作流。目标是让读者能讲清一篇论文的贡献、回到原文核查实验结论，并判断在自己的设备上复现需要哪些条件。

目前已确定需求与[验收表](docs/acceptance.md)。第一个开发里程碑是用 OpenVLA 验证单篇精读和本机 Zotero 入库。

## 两种请求

- **指定论文**。例如“帮我读 OpenVLA”。根据标题、作者、团队、日期或论文标识辨认目标。交付中文导读，并在本机 Zotero 的同一父条目下保存原文 PDF 和导读子笔记。
- **按主题找论文**。例如“从早到近梳理 VLA 的重要论文”。默认给约 6 篇，按首次公开时间排序，注明检索截止日，用原文说明每篇改变了什么技术选择。读者选中后再精读入库。

## 单篇交付

先用一段话交代背景、研究问题、方法和效果。再解释模型的输入与输出、关键设计、支撑结论的实验和适用边界。复现条件分推理、微调、仿真评测和真机实验说明。末尾默认推荐 3 篇相关论文，每篇附原文和一个值得带着读的问题。

## 开发顺序

1. 用 OpenVLA 完成单篇样品，打开本地 PDF、读回导读并验证重复运行。
2. 按样品反馈将规则与脚本封装成项目级 Codex Skill。
3. 加入按技术演进选文的主题阅读路线。
4. 在新对话中，用另一篇论文和一次中断重试验收可复用性。

Git 跟踪工作流规则、脚本和测试用例。论文 PDF、个人导读和 Zotero 数据保存在本机。需要暂存的阅读材料可放在仓库中由 Git 忽略的 `local/` 目录。
