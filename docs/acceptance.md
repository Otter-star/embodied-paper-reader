# 论文阅读工作流核验表

单篇精读检查第 1 至 6 项，主题路线检查第 7 项。每个适用项记录“通过、失败、待验证”之一，并填写证据。通过计 1 分，其余计 0 分。所有适用项通过才算完成。

| 项目 | 通过条件 | 结果 | 证据 |
| --- | --- | --- | --- |
| 1. 论文身份 | 标题、作者、标识符或出版记录能对应请求。区分首次公开与出版时间。线索冲突时先列出能区分候选的事实。 | | |
| 2. 方法与贡献 | 导读可回答研究背景、问题、方法和效果。模型输入、输出和关键设计可定位到正文。 | | |
| 3. 实验证据 | 每个核心数字与原文的指标、单位、基线、任务和真机或仿真环境一致。至少一项局限能定位到原文。 | | |
| 4. 复现条件 | 推理、微调、仿真、真机分别列代码或实验入口及所需条件；缺失项说明作者未报告或为何不适用。针对个人设备的判断列出依据。 | | |
| 5. 关联阅读 | 默认 3 篇。每篇提供可打开的一手来源、具体技术关系和阅读问题；实证材料不足时列出已确认篇数和缺口。 | | |
| 6. 入库与重试 | 在个人库中读回正确父条目，打开本地 PDF，读回同一父条目的中文导读。相同请求再次执行时，同版条目、PDF 和导读都没有新增副本。中断后仅补缺项。 | | |
| 7. 技术路线 | 注明检索截止日，按首次公开时间排列，每篇有来源、技术贡献和入选理由。声称的承接与比较关系能在一手文献中定位。读者选择前入库数为 0。 | | |

## OpenVLA 验收题

- **找的是哪一篇？** 原始 OpenVLA 对应 arXiv:2406.09246，首次公开于 2024 年，PMLR 论文集记录为 2025 年；OpenVLA-OFT 是后续独立工作。[预印本记录](https://arxiv.org/abs/2406.09246) · [正式出版记录](https://proceedings.mlr.press/v270/kim25c.html) · [OpenVLA-OFT](https://arxiv.org/abs/2502.19645)
- **16.5 的含义是什么？** 作者报告在 29 项任务上，相较 RT-2-X，任务成功率高出 16.5 个百分点。将其解释为模型自身的成功率应判失败。[OpenVLA 原文](https://arxiv.org/html/2406.09246v3)
- **约 27 GB 显存能做哪一步？** 官方仓库给出缩小批量进行 LoRA 微调的条件。读者应能从导读分辨该条件与完整训练、仿真和真机实验各自的要求。[作者的 LoRA 示例](https://github.com/openvla/openvla#fine-tuning-openvla-via-lora)
- **如何证明入库？** 记录本机回读的父条目标识和子项，实际打开 PDF，核对笔记，再执行相同请求并对照前后数量。个人库标识与笔记内容留在本地。

## 失败判定

虚构论文或证据位置、混用不同模型或实验的结果、将未经回读的写入报告为成功，任一项均判本次交付失败。只有摘要时标为摘要级概览。连接中断时记录已核验项与待补项。
